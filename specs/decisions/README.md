# Decision records

One page each: context, options considered, decision, because, consequences. One per week
minimum, on the biggest thing you were unsure about that week.

Why this is worth ten minutes a week:

- **For the agent** — it reads these and stops re-litigating settled choices every session.
- **For you in Week 7** — you will not remember why. The file will.
- **For an application or an interview** — a completed thought with alternatives considered
  and a cost accepted is precisely what judgment under uncertainty looks like on paper.

An ADR is never edited to match what happened. If a decision turns out to be wrong, write
the next ADR superseding it and say so in the `Status` line. The record of having changed
your mind for a reason is the valuable part.
